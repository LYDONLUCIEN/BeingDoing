## 怎样读历史

先查 [历史证据与替代链](../docs/HISTORY_EVIDENCE.md)、[ADR 状态](../docs/adr/README.md) 和 [GitHub 历史索引](../docs/ISSUE_HISTORY.md)，再进入原文。保留正文中的原决定和后续修订；只凭日期新、issue 关闭或勾选完成，不能认定已部署或永久不可改。

迁移记录与回滚依据、独有设计稿和无损母版继续保留；有新决定时记录替代关系和条件。清理旧执行器不授权删除真实数据。新的功能规范写入 docs；已发生的原因与过程写入 CHANGELOG／ADR，并链接原始证据。暂停的新产品讨论不属于当前 BeingDoing 开发要求。
