### 第二步：藏测试环境 —— career.beyondego.me 加 Basic Auth

在 dev 机执行：

```bash
# 生成密码文件（team 改成你要的用户名，回车后输密码）
htpasswd -cb /www/sites/career/.htpasswd team '你的强密码'
# 没有 htpasswd 就：apt install apache2-utils
# 或用 openssl 生成：printf "team:$(openssl passwd -apr1 '你的强密码')\n" > /www/sites/career/.htpasswd
```

1Panel → 网站 → career.beyondego.me → 配置文件，在 `location /` 反代块里加：

```nginx
location / {
    auth_basic "internal";
    auth_basic_user_file /www/sites/career/.htpasswd;
    add_header X-Robots-Tag "noindex, nofollow" always;
    proxy_pass http://127.0.0.1:3000;
    # ...其余 proxy_set_header 照旧保留
}

# robots.txt 放行给爬虫读（返回全站禁止，加速旧收录消亡）
location = /robots.txt {
    auth_basic off;
    default_type text/plain;
    return 200 "User-agent: *\nDisallow: /\n";
}
```
