# 报告 PDF 配色配置说明（2026-08-12 起）

> 适用对象：要调整 PDF 报告整体配色的人。**只改一个 JSON 文件，不需要动代码。**

## 机制

- 配色唯一入口：**`src/backend/app/static/styles/report_theme.json`**（扁平 key-value，十六进制色值）。
- 样式文件 `src/backend/app/static/styles/report_pdf.css` 中的 `{{token}}` 占位符，在每次生成 PDF 时由 `report_theme.json` 替换（`report_pdf_service._apply_theme`）。
- 报告总览页（预览页）的 HTML 由后端拼装（`report_pdf_service._overview_page_html`），颜色同样取自主题文件。

## 生效方式

1. 编辑 `report_theme.json`，保存。
2. **重启后端**（主题在进程内缓存，`_load_report_theme`）。
3. PDF 是**下载时即时渲染**的（`GET /export/report-pdf-download/{id}`），已生成的 markdown 不受影响——用户下次下载即得到新配色，**无需重新生成报告**。

## 整体换配色的建议路径

1. 先定主色：`accent`（正文强调）与 `overview_accent` + `overview_card_color_1..4`（总览页）建议同色系——当前正文是金（`#c9a96e`）、总览页是棕（`#8B4513` 系），**如要统一，把两边改成同一套主色**。
2. 再调中性色：`text_*`、`table_*`、`overview_*` 的灰/米色系列。
3. 改完重启后端，下载任意一份已生成的报告 PDF 即可预览效果（推荐用 `scripts/dump_report_pdf_input.py` 对应的测试 markdown 或直接下载线上报告验证）。

## 注意事项

- **JSON 语法**：注意逗号，改坏会在日志报「报告配色主题加载失败」并退回占位符原样（PDF 里会看到 `{{token}}` 字样，极易发现）。
- `_` 开头的 key 是注释，不会被当作颜色。
- 水印、页眉页脚 logo 是图片资源（`app/static/assets/`），不走配色文件。
- WeasyPrint 兼容性：总览页布局用 `<table>` 实现双列（不用 CSS grid/flex 多列），改样式时请保持这一约束。
