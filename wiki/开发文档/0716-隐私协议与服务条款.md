# 隐私协议 & 服务条款勾选 + 弹窗展示

> 本次改动为合规需要,在注册流程加入隐私政策/服务条款的阅读与同意确认,并在主页页脚提供协议弹窗查看入口。
> 文档日期: 2026-07-16。

## 一、需求

1. **注册页**: 增加隐私协议 + 服务条款的阅读确认勾选,**未勾选时不能注册**(表单内就地报错,不发请求)。
2. **主页页脚**: 页脚已有的"隐私政策""服务条款"两个链接(原本是死链 `/privacy` `/terms`),改为点击后**弹出模态层**展示协议正文,不跳新路由。

## 二、关键设计决策

| 决策点 | 选择 | 备选/理由 |
|---|---|---|
| 协议正文来源 | AI 生成中英文初稿,业务/法务后续替换 | 正文存在 i18n,用户可改 |
| 版本管理 | 文本开头写"最后更新: YYYY-MM-DD",改正文时手动同步 | 不引入后端"同意快照"字段(超出需求范围) |
| 展示形态 | 模态弹层(模态弹窗) | 不做独立路由页,不新开标签页 |
| 勾选交互 | 单 checkbox,同时同意两个协议;协议名做成可点击链接(点 → 弹层) | 不做双 checkbox |
| 页脚范围 | 只改主页 `LandingFooter` | 项目无全局 Footer,不抽公共组件 |
| 组件封装 | `<LegalDocLink>` 包装组件,自带 state + 弹层 | 两处调用(注册页 + 页脚)各一行 |
| 正文存储 | 独立文件 `legal.zh.ts` / `legal.en.ts` | 不撑爆主 i18n 文件 |
| 渲染格式 | 纯文本 + `whitespace-pre-line` | 不引入 markdown 解析依赖 |
| 触发器样式 | 透传 className/style,无图标 | 兼容主页(灰)与注册页(蓝)两套视觉语言 |
| 弹层关闭交互 | 点遮罩关闭 / ESC 关闭 / 背景滚动锁定 | 标准无障碍 + 防串滚 |

## 四、正文内容大纲(初稿)

替换为正式文本前,初稿章节结构如下,供业务/法务参考增删:

### 隐私政策(10 节)
1. 我们收集的信息(注册信息 / 对话内容 / 使用日志 / 可选语音)
2. 我们为什么使用
3. 存储与传输(HTTPS/TLS、密码单向哈希)
4. 第三方共享(LLM provider: DeepSeek/Kimi/Qwen/OpenAI)
5. 保留期限(注销后 30 日内删除或匿名化)

8. 未成年人(14 岁及以上)
9. 政策变更
10. 联系方式

### 服务条款(9 节)
1. 服务的性质(AI 辅助,非专业咨询)
2. 账号
3. 可接受使用
4. 内容归属
5. 服务变更与终止
6. 免责
7. 条款变更
8. 争议(中华人民共和国法律)
9. 联系方式

## 五、实现要点

### 5.1 弹层关闭交互(`LegalDocModal.tsx`)

- **ESC 关闭**: `useEffect` 监听 `window.keydown`,按 Escape 调 `onClose`
- **点遮罩关闭**: 遮罩是一个 `<button>` 覆盖 `absolute inset-0`,点击调 `onClose`
- **正文卡片**: `onClick={(e) => e.stopPropagation()}`,避免点正文也误关
- **防串滚**: 打开时 `document.body.style.overflow = 'hidden'`,关闭时还原
- **右上关闭按钮**: 内嵌 SVG X 图标,带 `aria-label="关闭"` 与 focus ring

### 5.2 `LegalDocLink` 的样式透传

```tsx
// 主页页脚(灰)
<LegalDocLink type="privacy" className="text-sm hover:underline transition-colors" style={{ color: 'var(--bd-fg-muted)' }} />

// 注册页(蓝)
<LegalDocLink type="privacy" className="text-primary-600 hover:text-primary-700 hover:underline mx-1 align-baseline" />
```

组件内部就是 `<button className={className} style={style}>{label ?? title}</button>`,完全透传给调用方。

### 5.3 `agreeTerms` 的 zod 校验

```ts
const registerSchema = z.object({
  // ... 其他字段
  agreeTerms: z.boolean(),
}).refine((data) => data.agreeTerms === true, {
  message: '请阅读并同意协议后继续',
  path: ['agreeTerms'],
});
```

未勾选时点注册: react-hook-form 阻止提交 → checkbox 下方红色文案 → 不发请求。

### 5.4 为什么正文不塞 `zh.ts` 主文件

- `zh.ts` 本身 439 行,协议各 3-5K 字 → 撑爆
- 协议改正文频率 ≠ UI 文案改正文频率,git diff 隔离更清爽
- `legal.*.ts` 作为纯字符串 `export const`,在主 i18n 里 `import` 后挂到 `footer` 块下,类型层无影响(`LocaleDict = Record<string, unknown>`)

### 5.5 重要:协议正文内禁用 `{xxx}` 占位

`useLocale().t()` 的实现会把 `{key}` 当作模板变量替换。协议正文里**不要写花括号占位**(例如不要写"剩余 {n} 天"),否则渲染时会被替换成字面量字符串。当前初稿无此类占位。
