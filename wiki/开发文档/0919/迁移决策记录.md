## 关键事实核查

- HTML 中**不存在 blur(6px)**；激活页背景模糊默认 10px，纸卡 12+10=22px，全站值域 4–28px。
- `#activate-values` 是 URL hash 而非页面/元素 id，对应现有 `/explore/activate`。
- `/explore/intro` 在 main 分支**确认存在**：5 步流程引导（STEPS×5）+ 分流逻辑（已登录且有已绑定 full 码 → 直达 activate）。
- HTML 默认气泡配色（RECOMMENDED_APPEARANCE）：**AI 深墨 #202832 底白字 / 用户纸白底深字**，不对称切角（AI `4px 19px 19px 19px`，用户反向），无左色条。
- 站内信在 HTML 中 = 右下固定 pill 悬浮球 + 右侧 456px 抽屉（blur 28px，双 tab 站内信/反馈）+ 个人空间嵌入面板，无独立路由页。

## 不可破坏边界（沿用 0919-newui 文档）

- 不改 API 参数、鉴权、数据结构与业务状态机；不伪造后端能力。
- 页面级作用域样式（`.ol-*`/稳定前缀），禁止无作用域全局选择器误伤首页与支付。
- `backdrop-filter` 必带 `-webkit-` 前缀；`color-mix` 先写静态回退；视口高度用 `.chat-shell-h`。
- 图片素材解码放 `public/assets/` 并 Git 跟踪，不用 base64。
- 每轮验收：`git diff --check`、`npm run lint`、`npm run build`。
