## 二、支付宝开放平台操作（约 30 分钟，含审核等待）

### 1. 创建应用

1. 登录开放平台 → 控制台 → 「网页&移动应用」→ 创建应用
2. 填写应用名称、图标，提交后得到 **APPID**（形如 `2021xxxxxxxxxxxx`）

### 2. 开通「当面付」产品

- 应用详情 → 产品列表 → 开通「**当面付**」
- 需要提交营业资质等资料，等待审核（沙箱应用默认已开通，可先用沙箱联调）

### 3. 配置密钥（接口加签方式）

1. 本地生成 RSA2 密钥对（2048 位）：

```bash
mkdir -p src/backend/certs && cd src/backend/certs

# 生成应用私钥
openssl genrsa -out alipay_app_private_key.pem 2048

# 导出应用公钥（用于上传到平台）
openssl rsa -in alipay_app_private_key.pem -pubout -out alipay_app_public_key.pem
```

> 也可以用支付宝官方「开放平台密钥工具」生成，效果相同。

2. 开放平台 → 应用 → 「接口加签方式」→ 选「**密钥**」→ 粘贴 `alipay_app_public_key.pem` 的内容上传
3. 上传后在平台上**查看/下载「支付宝公钥」**，保存为 `alipay_public_key.pem`

> ⚠️ 易错点：是「支付宝公钥」（平台生成），不是你本地生成的「应用公钥」，两者不同！验签用的是支付宝公钥。

### 4. 不用填的（别被页面迷惑）

| 配置项 | 操作 |
|---|---|
| 应用网关 | ❌ 不填（与支付通知无关） |
| 授权回调地址 | ❌ 不填（仅支付宝登录用） |
| openid 配置管理 | ❌ 不管 |
| 接口内容加密（AES） | 随意（支付接口不受影响） |

### 5. 服务器 IP 白名单

- 若设置了白名单，**必须包含服务器公网出口 IP**，否则下单/退款请求被拦截

## 三、服务器配置（约 10 分钟）

### 1. 放置密钥文件

```bash
# 在项目根目录
mkdir -p src/backend/certs
# 放入两个文件：
#   src/backend/certs/alipay_app_private_key.pem   ← 你的应用私钥（第二步生成）
#   src/backend/certs/alipay_public_key.pem        ← 平台下载的支付宝公钥
chmod 600 src/backend/certs/*.pem
```

> 该目录已加入 `.gitignore`，**绝不提交 git**。

### 2. 编辑 `.env`（项目根目录，203~206 行）

```bash
ALIPAY_APP_ID=你的APPID
ALIPAY_PRIVATE_KEY_PATH=src/backend/certs/alipay_app_private_key.pem
ALIPAY_PUBLIC_KEY_PATH=src/backend/certs/alipay_public_key.pem
ALIPAY_NOTIFY_URL=https://你的域名/api/v1/payment/notify/alipay
```

可选（沙箱时添加）：

```bash
# 沙箱网关；正式环境不写此行，默认 https://openapi.alipay.com/gateway.do
ALIPAY_GATEWAY=https://openapi-sandbox.dl.alipaydev.com/gateway.do
```

### 3. nginx 放行回调路径

支付宝异步通知地址 `POST /api/v1/payment/notify/alipay` **无登录鉴权**（靠 RSA2 验签防伪），nginx 必须放行 `/api/v1/payment/notify/*`：

- 现有 `location ^~ /api/` 反代规则已覆盖该路径（见 `deploy/nginx-api-stream.conf`）
- 若站点配置中有 IP 白名单 / 维护模式拦截 / Basic Auth，需对该路径豁免

### 4. 重启后端

```bash
./start.sh restart backend
```

## 四、沙箱联调流程（强烈建议先走）

1. 开放平台 → 「沙箱环境」：获取**沙箱 APPID**、配置沙箱密钥、下载「沙箱版支付宝」买家 APP
2. `.env` 填沙箱配置：
   ```bash
   ALIPAY_APP_ID=沙箱APPID
   ALIPAY_PRIVATE_KEY_PATH=src/backend/certs/alipay_app_private_key.pem
   ALIPAY_PUBLIC_KEY_PATH=src/backend/certs/alipay_public_key.pem   # 沙箱支付宝公钥
   ALIPAY_NOTIFY_URL=https://穿透域名/api/v1/payment/notify/alipay
   ALIPAY_GATEWAY=https://openapi-sandbox.dl.alipaydev.com/gateway.do
   ```
3. 本地/测试环境回调调试：用内网穿透（natapp / cpolar）把本地 8000 暴露为公网 HTTPS 临时域名
4. `./start.sh restart backend`
5. 网站下单 → 沙箱买家 APP 扫码付款 → 回调自动发码 → 个人空间「我的订单」查看
6. admin「支付管理 → 订单管理」测试退款（码未被使用时）
7. 沙箱验证通过后，`.env` 换回正式 APPID / 正式密钥 / 删掉 `ALIPAY_GATEWAY` 行，再重启

## 六、常见问题

| 现象 | 排查 |
|---|---|
| 下单返回 503 | `.env` 四项是否填齐；密钥文件路径是否存在、可读（相对项目根目录） |
| 下单报「验签/签名错误」 | 应用私钥与上传到平台的应用公钥是否同一对 |
| 支付成功但订单不变 granted | 回调地址公网不可达 / nginx 未放行；查后端日志 `alipay notify` |
| 回调验签失败 | `.env` 里放的是不是「支付宝公钥」而不是「应用公钥」 |
| 下单报「isp.bidder-pay-failed」类错误 | 服务器出口 IP 是否在平台白名单内 |
| 密钥读取失败 | 文件需为 PEM 纯文本格式，代码按 `Path(path).read_text()` 读取 |
