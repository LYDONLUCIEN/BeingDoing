# 1006 静态皮肤视觉回调：修复性能优化后的"三段白带"

> 日期：2026-10-06
> 触发：用户验收否决（截图 `wiki/开发文档/10-05/错误样子.png`）——chat/沉淀页变成明显的三段：`header.careering-chat-header` / 正文 / `div.careering-input-dock`，"整个页面都变丑了"
> 要求：性能不回退的前提下恢复以前的整页连续感
> 关联：docs/adr/0022（修订节）、claude-completed-2026-10-05-chat页面性能优化Phase1.md

## 根因

10-05 静态皮肤（`bd-static-skin.css`）按 `α'≈α+(1−α)·0.85` 把磨砂面换算成实色，产出 0.88–0.94 的高不透明度：

| 面 | 原磨砂 | 换算实色 | 后果 |
|---|---|---|---|
| 顶栏（两页） | 0.34+blur12 | 0.88 | 顶部实心白带，与背景硬切 |
| 输入区融底渐变（journey 全局） | 0.92 底 | 未覆盖 | 与遮罩条叠成底部大白带 |
| 滚动遮罩条 ::before/::after | —（mask 方案） | 0.92 | 自身成为白带 |
| 侧栏 / 对话卡 / 外壳 | 0.55–0.68+blur | 0.92–0.94 | 实心白板感 |

公式模拟的是"磨砂盖花背景"的观感；本项目背景是**近白柔光**，算出的高 alpha 全部过曝，原本玻璃+流光的**连续整页材质**被切成三条色带。

## 修复（零性能成本）

**实色 alpha 的绘制成本与数值无关**（同样一次无 blur 填充）——只回调数值，不动 backdrop-filter 禁令、不动动画冻结、不动布局。

新取值口径（`bd-static-skin.css` §2 注释已写明，勿再用公式重算）：

- **无内容从下方穿过的面**（header 两处）：0.88 → **0.34**，直接透出背景恢复连续感（studio 变体 0.55）
- **承载文字的面**：侧栏 0.94→**0.72**、对话卡 0.92→**0.72**、结论卡 0.96→**0.88**、classic 外壳 0.93→**0.75**
- **输入胶囊**：0.99→0.97（保持近实心，文字/光标清晰）
- **融底渐变**：0.92→**0.55**（新覆盖 `.careering-input-dock`，压掉 journey 的 0.92——"第三段"主因）
- **滚动遮罩条**：0.92→**0.66**（仍有滚动渐隐，不再自成白带）
- 回到底按钮 0.98→0.95

## 验证

- `npm run lint` 0 错误；`npm run build` 56 页通过
- 构建产物 grep（.next/static/css）：header 0.34 / dock 渐变 0.55!important / sidebar 0.72!important / 卡片 0.72 / 遮罩条 0.66 / 外壳 0.75 全部编译进 static-skin chunk（最后 import 层，同特异性源顺序取胜）✓
- playwright 实页验证受阻：ui_preview=1 预览路由被 explore 布局鉴权重定向、测试账号 pw-newpay 无激活码到不了沉淀真实页——CSS 层已按级联规则核实，**视觉请硬刷新确认**
- 性能：无 backdrop-filter / 无动画回归，填充成本不变，60fps 结论维持

# 二轮（同日晚）：用户再否决 → 「一块连续画布」定稿

## 用户二轮反馈

> "div.flex.min-h-0 就一个完整的聊天页面，为什么现在里面看起来还有一个矩形？header.careering-chat-header 和 div.careering-input-dock 这两个颜色和前面的主要聊天页面不一样，需要尽可能看不出来过度，而且过度的时候应该用模糊的处理，而不是直接切没了。"

对照正确版本截图（`wiki/开发文档/10-05/以前正确的样子.png`）：整页一块连续柔光画布，header 与正文零色差，输入胶囊像消息气泡一样浮在页面上。

## 本轮方法论

1. **视觉工具对比两版截图**：确认错误版 = "header 纯白 + 聊天区蓝灰 + 底部蓝灰色带，横向硬切 3-4 段"；正确版 = "融为一体无色差边界"。
2. **测量管线**：3100 临时 dev server（`ui_preview=1` 只在 dev 模式生效）+ playwright computed styles + elementFromPoint 分段 → 三区 tint 数据。
3. **像素级边缘检测**：截图喂回浏览器 canvas 逐行采样（`/tmp/pw-tools/pixel-analysis.js`），量化每条水平边界的 ΔRGB——一轮修复后 header/chat/dock 分区均值差已 ≤5（色带感主体已消），但检测到 4 处残留行跳变。

## 二轮改动（bd-static-skin.css，全部零性能成本）

| 处 | 一轮值 | 终版值 | 依据 |
|---|---|---|---|
| chat/V4 顶栏 | 0.34 实色 | **transparent** | 0.34 在带色背景上仍是 Δ≈5 白化带；header 下无滚动内容，背景直通 = 零色差 |
| 输入区融底渐变 | 0.55 渐变 | **background:none** | 任何 alpha 的通栏叠层都自成色带；胶囊自带表面（同消息气泡浮在页面上） |
| 遮罩条颜色 | 纸白 (251,252,251) | **背景实测色** chat (238,240,245) / V4 (240,241,246) | 条色与背景差 13-14，0.55 alpha 下端点跳变 Δ8-10（像素检测 y196/y770 实测）；改背景色后条对背景隐形、只对墨色内容渐隐，**端点跳变归零** |
| 遮罩条下沿高度 | 5.5/6rem | **7rem** | 渐变更缓，接近原 mask 的柔化观感 |

保留不动：header 发丝线 `rgba(23,33,45,.055)`（设计稿元素，正确版本存在）、backdrop-filter 禁令、动画冻结、§4 功能动效白名单。

## 二轮验证

- 像素检测复跑：**y196/y770 遮罩条边界消失**；仅剩 navbar 底边（站点外壳）、header 发丝线、侧栏底部插画三类设计边界；三区均值差 ≤5 且无行跳变 = 页面自身渐变连续过渡
- `npm run lint` 0 错误；`npm run build` 通过
- 构建产物 grep：static-skin chunk 含 `background:transparent` / `background:none!important` / `rgba(238,240,245,.55)` / `rgba(240,241,246,.55)` ✓（journey chunk 的 0.34+blur 被源顺序压掉）
- **视觉请硬刷新确认**（生产 3000 是 `next start`，旧标签页会引用已失效的旧 chunk）

## 可复用资产

- `/tmp/pw-tools/pixel-analysis.js`：截图 → 浏览器内 canvas → 逐行 ΔRGB 边缘检测（量化"还有没有色带"的工具，下次视觉回归直接用）
- V4 侧条色 (240,241,246) 是按 flow-light 底色系推算的（V4 真页需激活码未能实测），如沉淀页仍有轻微边界感，用同工具实测后微调该值
