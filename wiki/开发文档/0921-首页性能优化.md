# 0921 首页性能优化记录

> 2026-09-21 · 触发：用户反馈首页打开慢、每次刷新图片重新加载
> 代码改动已随 `fcedbd1`（部分错误进行修正）入库；遗留事项跟踪于 Issue [#95](https://github.com/LYDONLUCIEN/BeingDoing/issues/95)。

## 一、诊断结论（慢的根因，按影响排序）

| # | 问题 | 证据 |
|---|------|------|
| 1 | **nginx 强制 no-store，静态资源每次刷新全量重下** | `location /` 给所有响应加 `no-store`，而 `public/assets/`（约 7.7MB）无独立缓存规则，全部落入 `location /` |
| 2 | **两张巨型未压缩 PNG** | `home-scene.png` 2.2MB（2048×682 RGBA）、`testimonial-avatars.png` 2.3MB（精灵图，显示尺寸仅 42px） |
| 3 | 首页专用字体 2.3MB 走裸路径无缓存；jsdelivr 外链字体（霞鹜文楷）国内不稳定 | `openlife-regular/variable.woff2`；`app/layout.tsx` head 外链 |
| 4 | 全部裸 `<img>`，无懒加载、无 WebP、无响应式 srcset | 未使用 `next/image` |
| 5 | framer-motion 仅为旧浏览器提示弹窗就进首屏 bundle（~50KB gz） | `LegacyBrowserNotice.tsx` 静态 import |

补充认知：用户平时在 **dev 模式**（`--hot`）访问，dev 本身无编译优化、按需编译，先天比 prod 慢；图片压缩在 dev 下同样生效，但 JS 层面的慢只能用 prod build 消除。

## 二、改动清单

### 1. 图片压缩（WebP q85，Pillow method=6）

| 资源 | 原 | 现 | 说明 |
|------|-----|-----|------|
| `home-scene.png` → `.webp` | 2.2MB | **47KB** | 首屏 hero，RGBA PNG 极度浪费；`<img>` 加 `fetchPriority="high"` |
| `testimonial-avatars.png` → `.webp` | 2.3MB | **51KB** | 精灵图 1254px→504px（显示 42px，300% 百分比定位，缩图安全） |
| `botanical-scene.png` → `.webp` | 318KB | **113KB** | 保留 alpha；非首屏加 `loading="lazy"` |
| 3 张报告预览（已是 webp） | 489KB | 不变 | 补 `loading="lazy" decoding="async"` |

**首页图片负载 5.3MB → 约 0.7MB（-87%）**。原 PNG 保留作无损母版，勿删。
三张 webp 均已目检，水彩风格耐压缩，画质无感。

### 2. 缓存修复（"刷新重载"的根因修复）

- 新增 `deploy/nginx-static-cache.conf`：`location ^~ /assets/` 与 `/fonts/` → 30d immutable 长缓存
- `wiki/开发文档/0705-nginx.md` 完整配置同步插入「1.5 节」+ gzip 建议
- `next.config.js` 新增 `headers()` 同口径兜底（直连 Next 时生效；已实测响应头）
- HTML 页面保持不缓存（仅静态资源长缓存）

### 3. 版本号缓存击穿口径

`public/` 文件名不带哈希，**引用必须带 `?v=yyyymmdd`，更新资源时递增版本号即击穿缓存**。
已落实到本次全部引用点（page.tsx + openlife-reference-home.css）。

### 4. 首屏 bundle 瘦身

- `LegacyBrowserNotice` 拆为壳组件 + `LegacyBrowserNoticeDialog.tsx`（`next/dynamic` ssr:false），framer-motion 只在命中旧内核浏览器时才下载；构建清单确认首页 10 个 chunk 不含 framer-motion
- `app/layout.tsx` 加 jsdelivr `preconnect`

## 三、验证

- `npm run build` ✅ 通过
- 临时实例（端口 3100）实测响应头：`/assets/*.webp?v=20260921` 与 `/fonts/*` → `Cache-Control: public, max-age=2592000, immutable` ✅；HTML 页面不被浏览器长缓存 ✅

## 四、遗留事项（Issue 跟踪）

- [ ] **nginx 配置应用到生产服务器**（仓库与 wiki 已改，服务器面板需手工加两段 location，见 0705-nginx.md 新增 4；建议顺手开 gzip）
- [ ] 首页专用 openlife woff2 共 2.3MB，首访仍全量下载：可做字体子集化或迁 `next/font/local`
- [ ] jsdelivr 霞鹜文楷外链自托管，彻底去掉第三方依赖

## 五、编码准则（已沉淀 AGENTS.md「静态资源缓存口径（2026-09-21 起）」）

1. `/assets/`、`/fonts/` 引用必须带 `?v=yyyymmdd` 版本号，更新资源时递增
2. 新图片一律压成 WebP 再入库（q85，保留无损母版）
3. 非首屏 `<img>` 带 `loading="lazy" decoding="async"`；LCP 图带 `fetchPriority="high"`
4. framer-motion 等重型库不得进首屏 bundle，用 `next/dynamic` 按需加载
