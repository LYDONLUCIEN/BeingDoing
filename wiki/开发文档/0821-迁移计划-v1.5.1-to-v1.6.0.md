1. **migration 017/018/019**：`analytics_events`（埋点漏斗，ADR-0013）、`user_preferences`（支付弹窗「不再提醒」等）、`llm_usage_logs`（token 用量与成本统计）。0731 计划只写到 016，**这次 head 是 019**。
2. **xunlu 渲染引擎（ADR-0019，08-20）**：`RENDER_ENGINE=weasyprint`（默认）| `xunlu`（`src/report-renderer/` 精简 Node 渲染器，dist 已入库；需服务器有 Node≥20 + Chrome/Chromium）。**可先用 weasyprint 上线，xunlu 后续再切**——admin 报告页有运行时开关，即时生效。
3. **延期体系改版（ADR-0016，08-08）**：旧「20 元/+90 天分档延期」**已下线**，统一 **9.9 元/+7 天**（`RENEWAL_PRICE=990`/`RENEWAL_DAYS=7`）；新增**首次过期免费送 7 天**（每日 10:00 扫描 job + 邮件 + 站内信）。
4. **套餐码有效期从支付成功起算（ADR-0018，08-16）**：交付即 `expires_at = now + 天数`；团队分析联系邮箱变量化 `TEAM_ANALYSIS_EMAIL`（默认 xunlu.lab@outlook.com，仅联系地址，与发信通道无关）。
5. **年度套餐调价 159 元**（08-05 起，`ANNUAL_PRICE=15900`，代码默认值仍是 12800，**靠 .env 覆盖，漏配 = 线上卖 128**）。
6. **LLM 场景分流 + 密钥隔离（08-19）**：scene=chat → `deepseek-v4-flash`，rumination/report/其他 → `deepseek-v4-pro`；**测试/生产 DeepSeek key 完全隔离**——.env 放测试 key，生产 key 只放 .env.prod（systemd 另有 `/etc/beingdoing.env`）。
7. **报告复核体系（08-18）**：用户侧「重新生成」已下线，改「申请复核」；无额外设施，知道即可。
8. **SMTP 换 163 授权码（08-19）**：Outlook 在账号层面禁用个人邮箱 SMTP 基本认证，无解，回退 163（465 + SSL + 授权码）。
9. **start.sh 行为变化**：`start <env>` 会把环境记入 `.start_env`，之后 `restart`（含 `restart backend`）自动沿用同一套 `.env.<env>` 覆盖，不会丢配置。

## 1. 变化明细（部署视角）

### 1.1 数据库 migration（007 → 019，共 12 个，链路完整无分叉）

```
  → 010_feedback_and_notifications 用户反馈 + 站内信
  → 011_payment_and_membership     支付订单 / 折扣券 / 会员（会员不上线，ADR-0007）
  → 012_payment_order_qrcode       订单支付二维码字段
  → 013_packages_consultation_team 套餐 / 报告解读咨询 / 团队分析

  → 018_user_preferences           用户偏好（弹窗「不再提醒」等）

```

⚠️ 005（历史 migration）不可逆，升级前**必须备份数据库**。

### 1.2 激活码 schema 迁移（不进 alembic，独立脚本）

激活码存在 `data/simple/activations.json`（不在 SQL 库）。两个层次：

1. **必跑**：`scripts/migrate_activation_schema.py`——补 0726 批次字段（`code_type`/`vip_level`/`package_type` 等），存量码一律补为「完整码」。自动备份、幂等、后端运行中拒绝执行。详见 `0726-激活码schema迁移脚本说明.md`。
2. **不用跑**（运行时懒迁移兜底）：08-08 之后新增字段（`consumed_into`/`upgraded_from_code`/`free_renewal_offered_at` 等）由 `_load_all()` setdefault 兜底，无独立脚本、无需处理。
3. **可跑可不跑**：`scripts/backfill_upgraded_from_code.py`（消耗升级溯源反填）——旧生产 v1.5.1 没有支付功能，**不存在消耗升级记录，跑出来必然是 0**，可跳过；求稳就 `--dry-run` 看一眼。
4. **同理可跳过**：`scripts/backfill_rumination_lock.py`（回填 v4 终选未锁定报告）——v1.5.1 没有 rumination v4 数据，dry-run 应为 0。

### 1.3 支付模块（支付宝 P2a）

- 下单：**电脑网站支付 `alipay.trade.page.pay`**（收银台跳转 URL）。
- 回调：`POST /api/v1/payment/notify/alipay`（无登录鉴权，靠 RSA2 验签；已被 `location ^~ /api/` 覆盖，nginx 无需单独放行，但**维护模式会拦截**）。
- 同步回跳：`ALIPAY_RETURN_URL` → 前端 `/payment/result`。
- 密钥：`src/backend/certs/alipay_app_private_key.pem` + `alipay_public_key.pem`（**不进 git**，从旧服务器拷贝；.env 里路径为相对后端工作目录的 `certs/xxx.pem`）。
- 未配置密钥时下单接口 503，不影响其他功能。
- 商品目录（以 .env 为准）：季度 69 元 / 年度 **159 元** / 延期 **9.9 元+7 天** / 报告解读咨询 298 元。

### 1.4 报告 PDF：双渲染引擎（ADR-0019）

| 引擎 | 说明 | 服务器要求 |
|------|------|-----------|
| `weasyprint`（默认） | Python 内置渲染 | 系统库（libpango 等）+ `fonts-noto-cjk` 中文字体 |
| `xunlu`（可选） | `src/report-renderer/` 精简 Node 渲染器（抽自只读母版 `report/xunlu`），子进程调用，dist 已入库无需构建 | Node ≥20 + Chrome/Chromium |

- 分流优先级：admin 报告页运行时单选（存 `data/report_render_config.json`，即时生效）> `RENDER_ENGINE` env > 默认 weasyprint。
- **建议：本次迁移先用 weasyprint 上线**（依赖少、0731 已验证），xunlu 作为后续可选升级。若上线即启用 xunlu，Step 1 需额外装 Node≥20 与 Chrome/Chromium（`CHROME_PATH` 留空自动探测）。
- 报告配色只改 `app/static/styles/report_theme.json`（已进 git）+ 重启后端，详见 `0812-报告配色配置说明.md`。

### 1.5 LLM 配置（08-19 新口径，容易漏）

- **场景分流**（仅 deepseek 生效）：scene=chat（前四 phase 对话+结论卡）→ flash；rumination/report/team_analysis/未知 → pro。默认 `LLM_FLASH_MODEL=deepseek-v4-flash` / `LLM_PRO_MODEL=deepseek-v4-pro`，一般无需显式配置。
- **密钥隔离**：.env 只放**测试 key**；生产 key 只放 **.env.prod**（start.sh prod 叠加覆盖）或 systemd 的 `/etc/beingdoing.env`。
- **DB-first resolver**：vip_level=None 的旧 ReAct agent 链路读 `llm_model_configs` 表（is_default 行，key 加密入库）。**换 key 后必须同步**：`python scripts/sync_llm_db_config.py`（先 `--check` 只读对比 env 与 DB）。
- token 用量统计：`llm_usage_logs` 表 + 峰谷定价（`LLM_PEAK_HOURS`，默认 09:00-12:00,14:00-18:00），开箱即用。

### 1.6 品牌更名（ADR-0012）

- 新域名 `openlife.beyondego.me`；旧 `xunlu.*` 双域名 nginx **301 永久跳转**。
- CORS 只保留新 origin；`FRONTEND_URL` / `ALIPAY_NOTIFY_URL` / `ALIPAY_RETURN_URL` 全部指向新域名。
- 支付宝开放平台需同步修改**授权回调域**（唯一触碰的第三方平台配置）。
- 站内公告按域名前缀判定 prod（`siteNotices.ts`），新旧域名不可并行长期共存。

### 1.7 其他（无额外基础设施，知道即可）

- Rumination v4 矩阵组合模式；试用码门控（values 阶段限 10 轮，写端点超限 HTTP 402）；邮箱验证门控（未验证邮箱禁止探索写操作，403 `email_not_verified`）；账户注销 30 天冷存；报告解读咨询/团队分析；报告复核体系；admin 手动创建试用码。

### Step 6：1Panel 建站 + nginx 配置

1. **1Panel → 网站 → 新建网站**：域名 `openlife.beyondego.me`，申请 TLS 证书（Let's Encrypt）。
2. **反向代理**两条：
   - `/` → `http://127.0.0.1:3000`
   - `/api/` → `http://127.0.0.1:8000`，**用 `deploy/nginx-api-stream.conf` 的完整配置**（流式必须 `proxy_buffering off` + 300s 超时）。
3. **维护模式**：照 `0705-nginx-prod.md` 的「文件 1/2/3」三段配置，把所有 `xunlu` 路径替换为 `openlife`：
   - 主配置加 `set $maintenance_on` 检测块（flag 路径 `/www/sites/openlife/maintenance.flag`）；
   - `/` 和 `/api/` 两个反代 conf（在 `proxy/*.conf` include 里！）第一行加 `if ($maintenance_on = 1) { return 503; }`。
   - ⚠️ 维护模式会同时拦截支付宝回调——支付联调/上线期间避开维护模式。
4. 创建维护页目录：`mkdir -p <宿主机www路径>/sites/openlife/maintenance`。
5. **旧服务器 xunlu 站**：主配置改 301（切流时执行，见 Step 9）：

```nginx
server {
    listen 443 ssl;
    server_name xunlu.soulhappylab.com xunlu.beyondego.me;
    # ... 保留原 ssl_certificate 配置 ...
    return 301 https://openlife.beyondego.me$request_uri;
}
```

|------|------|

## 4. 关键坑位 TOP 10（踩过/高概率踩）

1. **certs / .env / app.db / data 都不在 git**——只 clone 代码等于什么都没迁。Step 0 的 tar 包是命根子。
2. **WeasyPrint 系统库 + 中文字体**——pip 装了 weasyprint 但没装 `libpango` / `fonts-noto-cjk`，PDF 直接崩或乱码。新服务器最容易漏。
3. **`NEXT_SERVER_ACTIONS_ENCRYPTION_KEY` 必须沿用旧值**——重新生成 + 前端 rebuild 后，用户端旧页面报 "Failed to find Server Action"。
4. **`ANNUAL_PRICE=15900` 靠 .env 覆盖**——代码默认还是 12800，漏配线上就卖 128 元。
5. **生产 DeepSeek key 只放 .env.prod**（或 `/etc/beingdoing.env`）——且换 key 后必须跑 `sync_llm_db_config.py`，否则旧 ReAct 链路用 DB 里的旧 key。
6. **1Panel 容器名和 www 挂载路径因版本而异**——不要照抄旧 prod 的容器名/路径；要么显式确认，要么 `NGINX_RELOAD_CMD` 留空让脚本自动探测。
7. **维护拦截 if 加在 `proxy/*.conf` include 文件里**，不是主配置——1Panel 反代的坑（详见 0705-nginx-prod.md）。
8. **支付宝验签用「支付宝公钥」**（平台下载），不是本地生成的应用公钥；**授权回调域不改** → 支付回跳/回调全挂。
9. **OSS bucket 若有 IP 白名单**，记得加新服务器出口 IP，否则反馈截图静默失败。
10. **SMTP 必须用 163 客户端授权码**（465+SSL），不能用邮箱登录密码；Outlook 个人邮箱 SMTP 基本认证已被微软禁用，不要再试。
