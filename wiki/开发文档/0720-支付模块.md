## 一、已完成的开发（无需配置即可用）

- **P1 折扣券**：admin 后台「支付管理 → 折扣券」创建/改额/作废；「邮件群发」勾选「附折扣券」自动逐人发券
- **P2a 支付宝闭环**：下单 → 跳转支付宝收银台（电脑网站支付 page.pay）→ 回调自动发码 → 回跳 `/payment/result` 结果页 / 我的订单 / admin 订单与退款（**密钥未配置时下单接口返回 503，不影响其他功能**）

> 2026-07-25 变更：支付产品由「当面付 precreate（展示二维码）」切换为「电脑网站支付 page.pay（跳转收银台）」（当面付开通需实体门店地址，不适用）。验签/发码/退款/超时关单链路不变。
>
> 2026-07-25 增补：支付宝异步回调偶发不到达，新增**主动查单对账兜底**——APScheduler 每 2 分钟扫描「pending 超 3 分钟且已出收银台 URL」的订单，用 alipay.trade.query 核实，TRADE_SUCCESS 即幂等交付（`payment_reconcile_orders` 任务）。即使回调完全丢失，订单也会在几分钟内自动完成交付。

## 二、支付宝开放平台配置（你需要操作的）

### 1. 不用填的（别被页面迷惑）

| 配置项 | 说明 | 操作 |
|---|---|---|
| 应用网关 | 接收平台消息用（生活号等），**与支付通知无关**，不是我们网站的网关 | ❌ 不填 |
| 授权回调地址 | 仅「支付宝登录/OAuth」用，我们不用支付宝登录 | ❌ 不填 |
| openid 配置管理 | 会员/营销类接口用 | ❌ 不管 |
| 接口内容加密（AES） | 仅「获取会员手机号」等能力强制，支付接口不受影响 | 随意 |
| 支付宝网关地址 | 不是填写项，代码已默认 `https://openapi.alipay.com/gateway.do` | 不用动 |

### 2. 必须确认的

| 配置项 | 操作 |
|---|---|
| 产品开通 | 应用 → 产品列表 → 开通「**电脑网站支付**」（需 ICP 备案网站，已签约✅）；同步回跳地址由代码按 `.env` 的 `ALIPAY_RETURN_URL` 逐笔指定 |
| 接口加签方式 | 选「密钥」；保存好**应用私钥**（本地生成的 pem）；在平台上查看/下载**支付宝公钥**（注意：不是应用公钥） |
| 服务器 IP 白名单 | 若设置了，**必须包含服务器公网出口 IP**，否则下单/退款接口被拦截 |

### 3. 支付异步通知的地址（最容易误解）

支付结果通知**不走「应用网关」**，而是每笔下单请求里用 `notify_url` 参数逐笔指定（代码已实现）。同理，付款完成后的浏览器回跳由每笔下单的 `return_url` 指定，指向**前端支付结果页**（同步回跳仅作展示，发码以异步 notify 为准）。你只要保证两个地址公网可达 + HTTPS：

```
ALIPAY_NOTIFY_URL=https://你的域名/api/v1/payment/notify/alipay
ALIPAY_RETURN_URL=https://你的域名/payment/result
```

本地调试回调：用内网穿透（natapp/cpolar 等）把本地 8000 暴露为公网 https 临时域名。

## 三、.env 配置清单（项目根目录）

```bash
# ===== 已填好，勿动 =====
ACTIVATION_CODE_PRICE=9900        # 激活码价格（分）
ACTIVATION_CODE_TTL_DAYS=180      # 有效期天数
DEFAULT_COUPON_AMOUNT=5000        # 邮件发券默认面额（分）
ORDER_TIMEOUT_MINUTES=30          # 订单超时关单
MEMBERSHIP_ENABLED=false          # 会员开关（未开放）
MEMBERSHIP_MONTHLY_PRICE=1500
MEMBERSHIP_LIFETIME_PRICE=29900
MEMBER_DISCOUNT_PERCENT=85

# ===== 需要你填（支付宝）=====
# ⚠️ 密钥路径相对「后端工作目录 src/backend」（start.sh / systemd 均 cd src/backend 启动），
#    写 src/backend/certs/... 会因路径拼接错误而读不到文件
ALIPAY_APP_ID=
ALIPAY_PRIVATE_KEY_PATH=certs/alipay_app_private_key.pem
ALIPAY_PUBLIC_KEY_PATH=certs/alipay_public_key.pem
ALIPAY_NOTIFY_URL=https://你的域名/api/v1/payment/notify/alipay
ALIPAY_RETURN_URL=https://你的域名/payment/result
ALIPAY_GATEWAY=https://openapi.alipay.com/gateway.do   # 沙箱改为 https://openapi-sandbox.dl.alipaydev.com/gateway.do

# ===== 微信（P2b 再做，先留空）=====
WECHAT_MCH_ID=
WECHAT_APP_ID=
WECHAT_API_V3_KEY=
WECHAT_CERT_SERIAL_NO=
WECHAT_PRIVATE_KEY_PATH=
WECHAT_NOTIFY_URL=
```

密钥文件放 `src/backend/certs/`（已加入 .gitignore，**绝不提交 git**）。

## 四、联调流程（本次直接正式环境，小额单验证；沙箱仅作备选）

> 电脑网站支付已正式签约，本次不走沙箱：用 0.01 元真实单跑通后退款即可。如需沙箱彩排：开放平台 → 沙箱环境拿沙箱 APPID/密钥，`.env` 换沙箱网关 + 穿透域名回调地址。

1. 开放平台确认「接口加签方式 = 密钥」（**不是证书**；.crt/.csr 为证书模式产物，忽略），保存好应用私钥 pem，平台复制**支付宝公钥**
2. 检查「服务器 IP 白名单」：若设置了必须包含服务器公网出口 IP
3. `.env` 填正式 APPID + 密钥路径 + NOTIFY_URL/RETURN_URL（正式网关）
4. `./start.sh restart backend`
5. 网站下单（建议 0.01 元测试单）→ 页面跳转支付宝收银台 → 付款 → 浏览器回跳 `/payment/result` 展示激活码 → 个人空间「我的订单」核对
6. admin「支付管理 → 订单管理」测试退款（旧 SKU 码未使用时）
