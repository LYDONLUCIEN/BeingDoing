| 维护 flag | `/opt/1panel/www/sites/xunlu/maintenance.flag` |
| 维护页 | `/opt/1panel/www/sites/xunlu/maintenance/` |

维护拦截已经写在主配置 + 两个 proxy conf 里。本次升级**不要**为了「对齐新文档」去改成 `openlife` 路径。  
系统自带的 `nginx` 服务保持 inactive，不要 `systemctl start nginx`（会和 OpenResty 抢 80/443）。

## 6. 常见问题

**Q：为什么不用文档里的 `/mnt/vdb1/miniconda3/envs/py312/bin/python`？**  
那个路径属于另一台机器。本机 conda 在 `/root/miniconda3`，只有 `base`。

**Q：为什么不用 `apt`？**  
本机是 Alibaba Cloud Linux 3，没有 apt。WeasyPrint 对应的包名是 `pango` / `cairo` / `gdk-pixbuf2` / `google-noto-sans-cjk-ttc-fonts`，不是 Debian 的 `libpango-1.0-0` / `fonts-noto-cjk`。

**Q：为什么不要 `./start.sh dev`？**  
`.env.dev` 指向 `career.beyondego.me`、维护路径 `zhiyinapp`、容器 `1Panel-openresty-hjWm`，全是别的环境。本机站点是 `xunlu` / `UpQ6`。

**Q：要不要把数据同步到新生产 `openlife.beyondego.me`？**  
那是另一份手册（`0821-迁移计划-v1.5.1-to-v1.6.0.md`）的事。本文只让**这台** `xunlu.soulhappylab.com` 在 v1.6.0 代码下能跑。

**Q：`python3 scripts/...` 能直接跑吗？**  
当前交互环境如果已经 `conda activate base`，`python3` 就是 3.13，可以。为防 PATH 被改乱，手册一律写 `/root/miniconda3/bin/python`。

**Q：支付宝怎么测？**  
本机没有 `certs/*.pem`，未配置时下单 503 是预期。沙箱联调见 `0723-支付宝配置操作文档.md`，不是本次必做。

**Q：升级后又报 oss2 / weasyprint？**  
说明 pip 没装进 **base**，或 `start.sh` 仍在 activate 一个不存在的 env。回到 Step 2 和 Step 5。
