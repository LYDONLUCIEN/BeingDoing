# 业务术语

产品、运营、开发共用的业务语言。现行术语与跨产品讨论术语分区；当前字段和实现见 [字段字典](DATA_DICTIONARY.md)。已退役概念仅在 [历史证据](HISTORY_EVIDENCE.md) 中解释，不列为现行模型。

## BeingDoing 现行业务术语

**账户（Account）**：一个人在各产品共享的身份与登录主体。购买、订阅和报告使用都关联账户，但相互不能代替。_Avoid_：用一张激活码代表一个账户。

**探索（Exploration）**：用户依次完成价值观、优势、兴趣、使命、沉淀并形成报告的一次旅程。_Avoid_：用「订阅」指一次探索。

**阶段（Phase）**：探索中的一个主阶段。兴趣阶段提炼的「热爱」可参与沉淀组合；二者不是两个额外阶段。

**试用激活码（Trial Code）**：限定价值观阶段及轮数的免费探索资格。**完整激活码（Full Code）**：一次完整探索及其报告的资格。_Avoid_：把完整码叫「会员」。

**购买者（Purchaser）**：购买订单并获得所交付商品的人。**激活人（Activator）**：实际认领激活码并使用探索的人。两者可不同。_Avoid_：只写「码所属人」而不说明是哪一角色。

**消耗升级（Consume-to-Upgrade）**：消耗一张未使用完整码，保留试用探索原有记录并升级资格。不是合并两个账户，也不是自动订阅。

**延期（Renewal）**：延长现有完整码的有效期。_Avoid_：与账户订阅续费混用。

**组合会话（Combo Session）**：沉淀 v4 中一个热爱与一个或多个优势组成的独立讨论单元。**选点草稿（Selection Draft）**：尚未提交创建组合会话的选择状态。_Avoid_：把草稿叫已创建会话。

**假设（Hypothesis）**：用户写下的可实践方向。**平衡点（Balance Point）**：该方向的内在渴望与当前实践条件是否相适应的咨询判断。_Avoid_：把推荐结果当成强制禁止用户选择的命令。

**报告审核（Report Review）**：完成探索后、用户读取报告前的审核过程。**报告复核（Report Recheck）**：针对已有报告问题提出的进一步处理申请。_Avoid_：与重新渲染 PDF 混用。

**报告授权（Report Authorization）**：激活人允许对应购买者读取报告的授权。授权不包含对话过程。

**支付订单（Payment Order）**：一次结算的记录。**订单明细行（Order Line）**：订单中一项交付及金额分摊单位。**退款申请（Refund Request）**：申请、审批、执行及核销的完整退款记录。_Avoid_：把下单、付清、交付当作同一状态。

**折扣券（Coupon）**：抵减订单金额的资格。**核销（Redemption）**：某订单实际占用/使用一次券资格。单次券与共享多次券的数量、归属规则不同。_Avoid_：把券码本身当成一次订单的核销记录。

## 现行业务关系

一个账户可以有多个订单和探索。订单购买者不一定是探索激活人。报告归属于探索，其授权独立于其他产品的购买资格。会员预留概念与探索激活码分别解释，不能把历史「永久」改称「年度」。

## 跨产品讨论术语（已暂停，尚未实施）

以下词义用于保留新产品讨论，未形成 BeingDoing 当前功能要求。讨论于 2026-10-13 暂停；规则状态与替代过程见 [跨产品边界](PRODUCT_EVOLUTION.md)。

**订阅（Subscription）**：账户在指定服务周期内获得特定产品能力的约定。月度、年度表示周期，不能直接代表可访问哪些资源。**权益（Entitlement）**：用户在具体产品与期限内可使用的能力。_Avoid_：用付款成功、vip_level 或运营标签直接代表全部产品权益。

**一次性商品（One-time Product）**：一次购买交付的课程、数据或知识内容等。可与订阅共用账户和结算能力，但交付与到期规则独立。

**购物车（Cart）**：待结算商品的集合。它本身不证明付款或获得权益。

**个人主页（Personal Homepage）**：一个账户唯一维护、持续更新的个人履历展示空间，汇集平台成长记录、平台认证及个人补充内容。_Avoid_：把主页等同于面向某个岗位的一份简历，或认为主页全部内容都经过认证。

**个人补充内容（Self-provided Content）**：用户提供的个人经历、作品、项目链接等履历材料。_Avoid_：把用户提供材料本身称为平台已认定的事实。

**资料真实性（Record Authenticity）**：个人经历和资料与事实相符的性质，是当前讨论中“可靠性”的主要含义。_Avoid_：用它表示道德优劣、未来履约保证、能力高低或性格适配。

**个人进展（Self-reported Progress）**：用户对自己在职业成长路径上推进情况或完成情况的记录与申报。_Avoid_：把自行标记完成称为已获得平台认证。

**平台成长记录（Platform Growth Record）**：平台记录的用户在平台内完成的步骤、参与经历及相关经验与成果。_Avoid_：把每条成长记录都称为能力认证。

**平台认证（Platform Credential）**：平台依据其认定标准，对用户的具体成果、能力或指标作出的正式认可。_Avoid_：与用户自述、登录认证、实名验证或对所有个人经历的真实性保证混用。

**职业成长路径（Career Growth Path）**：平台为用户输出的职业成长安排，包含需要达成的关键节点。_Avoid_：把规划中的目标当作已取得的成果。

**路径关键节点（Career Path Checkpoint）**：职业成长路径中具有重要意义、达成后可形成里程碑认证的目标。_Avoid_：与探索流程中的阶段混用。

**里程碑认证（Milestone Credential）**：平台对报告测评完成、职业成长路径关键节点达成等成长成果的认可，各里程碑表达对应的达成事实。_Avoid_：把不同里程碑统称为同一种职业能力证明。

**简历导出（Resume Export）**：从个人履历中按需筛选经历、选择展示内容和表达侧重点，形成面向具体用途的简历。多版本指不同的导出结果。_Avoid_：为每份导出简历另维护一套个人主页。

**公开摘要（Public Summary）**：一个人允许对外展示的履历概要，供他人作初步了解。_Avoid_：把可看摘要等同于可看完整履历、认证证据或私密资料。

### 讨论中的关系

订阅资格与一次性商品可以并存，账户身份、订单和权益分别解释。个人主页每个账户仅维护一份，简历可基于其中的履历内容导出多个版本。成长记录与认证含义不同，里程碑认证属于平台认证，个人补充内容的来源也不会因为进入同一主页而改变。记录存在与向他人展示是不同概念。
