## 2026-10-12 · clean 第二轮：退役 v3、纠正历史口径

**触发**：维护者指出第一轮“保留 v3 后端”与当前淘汰意图冲突，字段字典也仍展示旧矩阵概念；要求核查开发记录和 GitHub 讨论。

**核查过程**：读取 GitHub 全量102个issue、1个PR记录及114条评论，结合本地开发文档、ADR、Git提交和当前调用关系核对。区分提出、接受、实现、部署四种状态；发现11轮门槛、固定旧锁定、随机审核时限等已被后续提交替代；年度159元决定与已落地128元默认之间仍有证据缺口。

**代码结果**：

- 从 simple-chat 删除七步/矩阵运行接口、协议、专属提示词与辅助模块；通用写入口对旧沉淀阶段返回410。
- 保留当前 v4 独立会话 ID、用户假设、后台平衡判断及终选。共用四阶段输入提取为小模块。
- 版本查询固定 v4，移除运行 A/B 服务/配置；旧表模型和历史迁移仅用于存量识别及账户删除。
- 后台跳转改用 v4；沙箱上游回退同步清理下游状态；历史导出只读；批量报告从原生 v4 快照恢复，不再从旧矩阵伪造用户结论。
- 同步移除专属旧测试、修复脚本和回放模板入口，新增边界回归。实际历史数据和报告没有修改。

**文档结果**：当前字段字典仅解释当前组合；新增 DECISIONS、HISTORY_EVIDENCE、ISSUE_HISTORY、ADR-0025；历史入口与旧 ADR 标注状态和替代链。明确哪些是安全/语义不变量、哪些依赖存量数据、哪些只在特定阶段成立，哪些尚未实施。

**验证**：先运行退役用例得到19项失败，再实现后验证拒绝路径与原生 v4；扩大到后台、提示词、试用和导出共132项通过。最终全量、前端检查与复审以 [TESTING](TESTING.md) 和 [REVIEW](REVIEW.md) 为准，未部署。
