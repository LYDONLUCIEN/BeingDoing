# ADR-0006: 激活码与会员是两条独立产品线，高级模型权益购买时固化

**状态**: accepted
**日期**: 2026-07-19
**决策者**: 产品 + 开发 Grill

## 背景

权益模型有两条路线：A) 支付只负责发放/延期激活码（会员只是标签）；B) 用户级会员体系，会员免激活码直接用（需改动全部激活码门控）。

## 决策

**两条路线都否决**，采用第三条：**激活码与会员是两条独立产品线**。

- 激活码 = 一次性消耗品，**所有用户（含会员）都必须购买**，会员不免码。
- 会员（包月/永久）= 账户级长期服务，v1 权益仅两项：① 购买激活码享会员折扣（自动生效，与折扣券无关）；② 会员购买的激活码固化 `vip_level=2`。
- 高级模型权益**购买时固化到码上**（会员期间买的码永久 vip_level=2），**不做运行时动态判定**——聊天链路 60+ 处 vip_level 检查点零改动，会员到期不会出现进行中 journey 模型突兀降级。

## 后果

- User 表需新增会员缓存字段（plan / expires_at），由订阅变更时维护。
- 「会员折扣与折扣券能否叠加」**已决（2026-07-19 补记）**：可叠加，先算会员价（原价×0.85，四舍五入到分）再减券面额，实付下限 0 元。
- 发码方式为「发码自取」（成功页展示+邮件备份，码不绑定购买者可转送），订单归属购买者——退款归属判定因此只看订单，不看码的 claim 者。
