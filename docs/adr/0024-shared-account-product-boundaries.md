# ADR-0024：跨产品共用账户，交易与产品权益分离

**状态**：accepted（边界决策；订阅/购物车实现尚未开始）
**日期**：2026-10-12
**决策者**：项目所有者

## 背景

现有产品通过一次性套餐交付探索激活码及报告；未来产品以月/年订阅为主，也可能售卖一次性课程、数据和知识内容。所有者明确要求共用账户，并能关联历史订单、券、激活码和报告。

## 决策

共享现有 users.id 与认证体系。账户身份、交易、订阅周期、产品权益、探索/报告各有独立含义。新产品不强制发行激活码，不以 vip_level、运营标签或旧套餐名称推导订阅资格。

历史报告可按激活码索引查询，但仍按激活人/获授权购买者及报告审核规则授权。对话过程不随报告共享。保留老会员 monthly/lifetime 模型，不能将 lifetime 原地改义为 annual。

订阅扣款模式、产品权限、跨产品券范围及购物车结算规则尚待定稿，未在本次清理中新增生产表或自动扣款。

## 理由与影响

复用身份可避免账户重复与历史资源断链；分离权益可支持订阅和一次性商品并存，避免把付款或激活码存在当作通用权限。代价是后续需要明确产品目录、周期状态机、幂等交付及撤权机制。实施清单见 [新产品边界](../PRODUCT_EVOLUTION.md)。
