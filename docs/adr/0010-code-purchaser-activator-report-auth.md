# ADR-0010: 激活码双角色（所属人/激活人）与报告授权边界

**状态**: accepted
**日期**: 2026-07-20
**决策者**: 产品 + 开发 Grill

## 背景

年度套餐的赠品码可转送他人，团队分析需要汇总多份报告，产生了「购买者能否看到被赠者数据」的隐私边界问题。曾讨论过授权码/邮箱授权等通用分享机制，被否决（逻辑太复杂）。

## 决策

- 码有双角色：**所属人**（购买者，订单归属）与**激活人**（使用者，claim 归属）。
- 所属人可看到自己订单交付的所有码「被谁激活」；**仅当激活人在报告页一键授权后**，所属人才能看到该码的**报告**（用于团队分析）。
- **对话过程记录任何情况下不可分享、不可授权**——系统层面不提供该能力。
- 授权仅限「激活人 → 所属人」一个方向，无通用分享机制。

## 后果

- 激活码记录需携带来源订单/购买者标识（赠品码归属可溯）。
- 团队分析的报告候选 = 自己名下码的报告 + 自己订单交付且已授权的码的报告。
- 激活赠品码时页面需告知「该码报告可被你授权给赠送者」。
