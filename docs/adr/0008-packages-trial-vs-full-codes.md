# ADR-0008: 套餐体系取代单一 SKU，激活码分试用/完整双维度

**状态**: accepted
**日期**: 2026-07-20
**决策者**: 产品 + 开发 Grill
**取代**: 「全程激活码 ¥99/180 天」单一 SKU 决策（ADR-0005 中的商品定义部分；ADR-0006/0007 会员体系保留并存，本期不上线）

## 背景

原商业模式为单一 SKU「全程激活码 ¥99/180 天」。产品调整为免费试用 + 套餐付费模型。

## 决策

- 激活码增加**试用/完整**维度（`code_type`）：试用码注册即送、自动绑定、不过期，限 values 阶段 10 轮问答（第 11 条用户消息起拦截；values 内已出结论卡要推进 strengths 同样拦截）；完整码解锁全部，vip_level=2（试用=1，当前两档均配置为 DeepSeek）。
- 商品目录：**季度套餐 ¥69/3 个月**（升级 1 码）、**年度套餐 ¥99/1 年**（1 升级 + 2 赠品码）、**延期激活**（季度码 ¥23/3 月、年度码 ¥33/1 年，从 max(当前到期, 现在) 追加）、**报告解读咨询 ¥298/次**。旧单一 SKU 下架，已售订单不受影响。
- 有效期锚点：升级码从付款起算；赠品码从首次激活起算；购买时间仅作审计。
- 存量码（本功能上线前）一律视为完整码。

## 后果

- `ActivationRecord` 需新增 `code_type`、`package_type`（决定延期价格档位）、`activated_at`（首次使用时间，有效期锚点）等字段；JSON 存储做 setdefault 兼容。
- 支付交付逻辑从「一律发新码」改为按商品类型分支（升级/发码组/延期/咨询预约单）。
- 对话流入口新增试用码轮数门控（写端点拦、只读端点不拦，admin/沙箱豁免）。
